# Collections

Voice Note Collections, v3 style: each collection is a markdown file grouping notes by `[[wikilink]]` — dynamic, portable, Obsidian-friendly. Types: `area` · `project` · `topic` (auto-maintained from note frontmatter), `theme` (saved searches), `manual` (hand-picked).

Created and maintained by `/vn-catalog` — see `docs/frontmatter-schema.md` for the format and `docs/examples/example-collection.md` for a worked example. Prose you write above a collection's `## Notes` heading is preserved; the list below it is regenerated.
